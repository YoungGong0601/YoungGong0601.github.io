마크다운으로는 글자와 이미지까지가 한계다. `.mdx` 로 저장하면 같은 글 안에서 컴포넌트를 불러 쓸 수 있고, 그 컴포넌트는 브라우저에서 실제로 동작한다. React 같은 프레임워크를 붙이지 않아도 된다.

## 버튼

아래는 Astro 컴포넌트 하나를 본문에 심은 것이다. 눌러보면 숫자가 바뀐다.

<CounterButton label="눌러보세요" start={0} step={1} />

같은 컴포넌트를 값만 바꿔 여러 번 쓸 수 있다. 서로 상태를 공유하지 않는다.

<CounterButton label="10씩" start={100} step={10} />

글에서 쓰는 방법은 두 줄이다. 파일 맨 위에서 불러오고, 본문 아무 곳에나 쓴다.

```mdx
import CounterButton from "@/components/demo/CounterButton.astro";

<CounterButton label="눌러보세요" start={0} step={1} />
```

## 그래프

데이터를 배열로 넘기면 SVG를 서버에서 미리 그려 보낸다. 선이 그려지는 애니메이션과 점 호버 표시만 브라우저에서 처리한다.

<LineChart
  data={[12, 19, 14, 27, 24, 35, 31, 42]}
  labels={["1월", "2월", "3월", "4월", "5월", "6월", "7월", "8월"]}
  caption="월별 글 수 (예시 데이터)"
  unit="편"
/>

점에 마우스를 올리면 아래에 값이 나오고, 다시 그리기를 누르면 선이 처음부터 다시 그려진다. 키보드 탭으로도 점을 옮겨 다닐 수 있다.

```mdx
<LineChart
  data={[12, 19, 14, 27, 24, 35, 31, 42]}
  labels={["1월", "2월", "3월", "4월", "5월", "6월", "7월", "8월"]}
  caption="월별 글 수 (예시 데이터)"
  unit="편"
/>
```

값이 하나만 바뀌어도 다시 계산해서 그리므로, 수치를 고칠 때 그림 파일을 다시 뽑을 필요가 없다.

## 이렇게 만든 이유

그래프를 넣는 방법은 크게 세 가지다.

| 방법 | 장점 | 단점 |
| --- | --- | --- |
| 이미지로 캡처 | 가장 간단하다 | 수치가 바뀌면 다시 뽑아야 하고 확대하면 흐려진다 |
| 차트 라이브러리 | 기능이 많다 | 방문자가 라이브러리를 내려받아야 한다 |
| SVG 직접 그리기 | 추가 용량이 없고 테마 색을 그대로 쓴다 | 필요한 그림 종류마다 코드를 써야 한다 |

꺾은선 하나에 라이브러리를 붙일 이유가 없어서 세 번째를 골랐다. 그래프 뼈대는 빌드 때 SVG로 완성되고, 브라우저가 받는 스크립트는 애니메이션과 호버 처리뿐이다.

> 컴포넌트 안의 색은 모두 사이트 테마 변수(`--accent`, `--border`)를 쓴다. 다크모드로 바꾸면 그래프도 같이 바뀐다.

## 주의할 점

- 동작이 필요한 글만 `.mdx` 로 저장한다. 나머지는 `.md` 가 편하다
- 옵시디언에서 `.mdx` 를 열면 `import` 줄과 컴포넌트 태그가 그냥 글자로 보인다. 편집은 되지만 미리보기는 깨진다
- 컴포넌트 하나를 여러 번 쓰면 스크립트는 한 번만 받고, 각 인스턴스를 순회해서 붙는다
