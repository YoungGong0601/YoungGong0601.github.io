기본 Astro 블로그 스타터로 시작했는데, 글이 쌓이기 시작하니 목록을 날짜순으로 한 줄씩 나열하는 것만으로는 부족했다. 같은 주제를 묶어 보고 싶었고 본문 검색도 필요했다. 직접 붙이는 대신 태그와 검색이 이미 들어있는 테마로 갈아타기로 했다.

## 왜 옮겼는가

직접 붙이는 쪽도 계산해봤다. 태그는 스키마에 필드 하나 늘리고 동적 라우트를 만들면 30분이면 끝난다. 문제는 검색이었다. 정적 사이트에서 본문 검색을 하려면 색인을 만들어야 하고, 그걸 직접 굴리면 관리 대상이 하나 늘어난다.

AstroPaper는 이 둘을 다 갖고 있었다.

- 태그와 카테고리가 frontmatter에 들어있다
- Pagefind 기반 정적 검색이 빌드에 포함된다
- 페이지네이션, 다크모드, OG 이미지 자동 생성이 딸려온다

글이 한 편뿐인 지금이 갈아타기 비용이 가장 싼 시점이라는 점도 컸다.

## 옮기면서 밟은 지뢰

### frontmatter 이름이 다르다

가장 먼저 걸린 건 날짜 필드였다. 기존 스타터는 `pubDate`, AstroPaper는 `pubDatetime`을 쓴다. 이름만 바꾸면 되는 일인데, 여기서 내가 일괄 치환 정규식을 잘못 써서 글 6개의 본문을 날려먹었다.

```python
# 이렇게 쓰면 안 된다
re.sub(r"(?ms)^tags:\n(?:  - .*\n)+", block, s)  # [!code --]
re.sub(r"(?m)^tags:\n(?:  - .*\n)+", block, s)   # [!code ++]
```

`(?s)` 플래그를 붙이면 `.`이 줄바꿈까지 먹는다. `  - .*\n`이 파일 끝까지 삼켜서 닫는 `---`와 본문이 사라졌다. 빌드가 바로 실패해서 금방 알아챘지만, 플래그 하나로 이런 일이 생긴다는 게 새삼 무서웠다.

> 콘텐츠 스키마가 필수 필드를 잡아주는 덕에 조용히 배포되지 않았다. 타입 검사가 있는 쪽이 이럴 때 확실히 유리하다.

### 옵시디언 볼트 경로를 유지하기

AstroPaper는 글을 `src/content/posts`에서 읽는다. 내 볼트는 `src/content/blog`에 있었다. 볼트를 옮기는 대신 상수를 바꿨다.

```ts
// src/content.config.ts
export const BLOG_PATH = "src/content/blog";
```

한 줄이면 되는 일을 파일 수십 개 이동으로 처리할 이유는 없다.

### 템플릿 폴더가 글로 읽힌다

AstroPaper의 glob 패턴은 밑줄로 시작하는 **파일**만 제외한다. 폴더는 걸러지지 않아서 옵시디언 템플릿(`_templates/post.md`)이 글로 잡혔다. 템플릿에는 `{{date:YYYY-MM-DD}}` 같은 치환자가 들어있으니 날짜 파싱이 당연히 실패한다.

```ts
loader: glob({
  pattern: ["**/[^_]*.{md,mdx}", "!**/_*/**"],
  base: `./${BLOG_PATH}`,
}),
```

### 무효한 CSS 선언이 링크를 파랗게 만든다

테마와 무관하게, 기존 스타터에서 넘어온 버그도 하나 잡았다. 헤더 링크가 의도와 달리 파랗게 나왔다.

| 선언 | 결과 |
| --- | --- |
| `--black: 15, 18, 25` | RGB 숫자 세 개일 뿐 색이 아니다 |
| `color: var(--black)` | 무효 선언으로 버려진다 |
| `a { color: var(--accent) }` | 대신 이게 적용되어 파란색 |

`rgb(var(--black))`으로 감싸면 해결된다. 원인을 모르고 헤더에만 색을 덮어썼다면 같은 규칙을 쓰는 다른 링크는 계속 파란 채로 남았을 것이다.

## 남은 것

- 표가 본문 폭을 넘어가면 잘린다. rehype 플러그인으로 감싸는 처리가 필요하다
- Pagefind는 한국어 어간 분석을 지원하지 않는다. 검색은 되지만 어미 변화를 넘나드는 매칭은 안 된다
- 글마다 썸네일을 넣는 습관을 들여야 목록이 심심하지 않다

## 정리

테마 교체에서 시간을 먹은 건 디자인이 아니라 **데이터 규격 차이**였다. 필드 이름, 콘텐츠 경로, glob 패턴 세 가지. 다음에 또 옮길 일이 있다면 이 세 개를 먼저 맞춰놓고 시작하겠다.
